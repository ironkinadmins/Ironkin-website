Maintenance & recovery

Use these only if an existing cycle is blocked or missing a WOM link. No historical payout is changed by viewing these tools.

Recover an interrupted cycle Verify existing WOM IDs or reconcile archives

Attach an existing WOM competition

Use only when WOM already created the competition but the website lost its ID. The server checks the WOM group, metric, and title before attaching.

Reconcile an interrupted archive

Use only after checking the archive and WOM results. This action requires an existing matching archive, closes its exact active event if needed, and marks the cycle completed. It never posts Discord results, creates WOM competitions, or awards Embers. If no archive exists, the cycle remains blocked for manual investigation.

Diagnostics Read-only checks and optional integration tests

Test WOM connection

Safe read-only check of WOM group access and automation prerequisites. Does not create competitions, change events, post to Discord, or pay Embers.



A successful connection check does not confirm permission to create WOM competitions. Creation must be tested separately with explicit confirmation.
Automation Test Center


Read-only simulations using the saved cycle configuration and records. No WOM calls, Discord messages, event changes, or Ember payments. PASS means a local prerequisite passed, not that the external integration has been live-tested.





Test WOM competition creation


This creates one real, public, 24-hour test competition in WOM group 12095, starting approximately 15 minutes after confirmation. It does not modify the BOTW/SOTW schedule, post to Discord, or award Embers. You must remove the test competition manually from WOM afterward.






If creation returns an uncertain result, check WOM before attempting anything else. The system blocks automatic retries to avoid duplicates.
